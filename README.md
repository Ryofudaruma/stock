# 株価アラート(Windows 版)

登録した日本株・米国株の株価を **一定間隔(初期設定は30分)** でチェックし、あらかじめ決めた金額(閾値)**以下** になったら **メール** でお知らせする Windows 用のアプリです。

- **PC が起動している間だけ** 動きます。Windows にサインインすると自動で起動するように設定できます。
- 監視する銘柄は **画面で会社名を検索して選ぶ** だけで登録できます(例: 「トヨタ」「ソニー」「Apple」)。
- 同じ銘柄について、**同じ日(日本時間)に何度もメールは送りません**。一度閾値を上回ってから再び下回った場合は、改めて通知します。

通知メールの例(件名: 株価アラート):

```
【株価アラート】トヨタ自動車(7203.T)
現在値: 2,450
設定した閾値: 2,500 を下回りました。
```

## 1. 必要なもの

- Windows 10 または Windows 11 の PC
- インターネット接続
- Gmail アカウント(通知メールの送信に使います。受け取りは他のメールアドレスでも OK)

## 2. Python をインストールする

このアプリは「Python(パイソン)」というプログラムの上で動きます。すでにインストール済みの場合は飛ばしてください。

1. <https://www.python.org/downloads/windows/> を開きます。
2. **Download Python 3.x.x**(3.11 以上ならどれでも OK)の黄色いボタンを押して、インストーラーをダウンロードします。
3. ダウンロードしたファイル(`python-3.x.x-amd64.exe`)をダブルクリックします。
4. 最初の画面の下にある **「Add python.exe to PATH」にチェックを入れて**、**Install Now** を押します。
   - 「Use admin privileges when installing py.exe」にもチェックが入っていれば、そのままで大丈夫です。
5. 「Setup was successful」と表示されたら **Close** を押します。

> Microsoft Store 版の Python でも動きますが、上記の公式サイト版をおすすめします。

## 3. アプリをダウンロードしてセットアップする

### 3-1. ダウンロード

1. このリポジトリの GitHub のページを開きます。
2. 緑色の **Code** ボタン → **Download ZIP** を押します。
3. ダウンロードした ZIP ファイルを右クリック → **すべて展開** を押し、展開先を選んで展開します。
   - 展開先はどこでも構いませんが、**あとから移動しない場所**(例: `ドキュメント` フォルダの中)がおすすめです。

### 3-2. セットアップ(最初の1回だけ)

1. 展開したフォルダを開き、**`setup.bat`** をダブルクリックします。
   - 青い画面で「Windows によって PC が保護されました」と表示された場合は、**詳細情報** → **実行** を押してください(インターネットから入手したファイルに表示される確認画面です)。
2. 黒い画面が開き、必要なライブラリのインストールが始まります。数分かかることがあります。
3. 「セットアップが完了しました。」と表示されたら、何かキーを押して画面を閉じます。

### 3-3. 起動

- フォルダ内の **`start.bat`** をダブルクリックすると、アプリの画面が開きます。
- 初回起動時は、日本株の会社名検索に使う「東証の銘柄一覧」を自動でダウンロードします(数秒〜数十秒)。

> デスクトップから起動したい場合は、`start.bat` を右クリック → **その他のオプションを確認** → **ショートカットの作成** で作ったショートカットをデスクトップに移動してください。

## 4. Gmail のアプリパスワードを発行する

アプリパスワードは、このアプリが Gmail からメールを送るための「専用パスワード」です。**普段の Google アカウントのパスワードは使いません。**

1. Google アカウントで **2段階認証プロセス** を有効にします。
   - <https://myaccount.google.com/signinoptions/two-step-verification> を開き、案内に従って設定します(すでに有効なら不要)。
2. <https://myaccount.google.com/apppasswords> を開きます。
3. **アプリ名** に分かりやすい名前(例: `株価アラート`)を入力して **作成** を押します。
4. 表示された **16文字のパスワード** をコピーします(次の手順ですぐ使います)。
   - この画面を閉じると二度と表示されません。忘れた場合は、同じページで削除して作り直してください。

> 会社や学校の Google アカウントでは、管理者の設定によりアプリパスワードが使えないことがあります。その場合は個人の Gmail アカウントを使ってください。

## 5. メールの設定をする

1. アプリの **メール設定** タブを開きます。
2. 次のように入力します。

| 項目 | 入力する内容 |
|---|---|
| 送信元メールアドレス | 4 でアプリパスワードを発行した Gmail アドレス(例: `yourname@gmail.com`) |
| アプリパスワード | 4 でコピーした16文字のパスワード(スペースは入っていても OK) |
| 送信先メールアドレス | 通知を受け取りたいアドレス。**空欄なら送信元アドレス(自分)宛て** に送ります |
| SMTPサーバー | `smtp.gmail.com` のまま |
| SMTPポート | `587` のまま |

3. **保存** を押します。アプリパスワードの右に「保存済み」と表示されれば OK です。
4. **テストメールを送信** を押し、テストメールが届くことを確認します。
   - 届かない場合は迷惑メールフォルダも確認してください。

> アプリパスワードは Windows の「資格情報マネージャー」に安全に保存され、アプリのフォルダ内のファイルには書き込まれません。保存後に欄が空に戻るのは正常です。

## 6. 監視する銘柄を登録する

1. **監視銘柄** タブで **+ 銘柄を追加…** を押します。
2. 検索欄に **会社名・証券コード・ティッカー** を入れて **検索**(または Enter)を押します。
   - 日本株の例: `トヨタ`、`とよた`、`7203`、`ソニー`
   - 米国株の例: `Apple`、`AAPL`、`Microsoft`、`NVIDIA`
3. 一覧から銘柄をクリックすると、下に **現在値** が表示されます。
4. **通知する価格(閾値)** を入力します。
   - 「現在値の -5% / -10% / -20%」ボタンを押すと、その価格が自動で入ります。
   - 閾値は **その銘柄の通貨** です。日本株は **円**、米国株は **ドル**(換算はしません)。
   - 現在値が閾値と **同じか、それより低く** なったときに通知します。
5. **この銘柄を追加** を押すと、一覧に追加されます。

### 閾値の変更・削除

- 変更: 一覧で銘柄を選んで **閾値を変更…**(または行をダブルクリック)
- 削除: 一覧で銘柄を選んで **削除**(または Delete キー)

## 7. PC の起動時に自動で起動させる

1. **その他の設定** タブを開きます。
2. **「Windows にサインインしたときに自動で起動する」** にチェックを入れます。

次回から、Windows にサインインするとアプリが **最小化した状態** で自動的に起動し、監視を始めます(起動から約1分後に最初のチェックを行います)。
やめたいときはチェックを外してください。

## 8. 普段の使い方

- **アプリが起動している間(最小化していても)**、設定した間隔で株価をチェックします。画面下のステータスバーに「最終チェック」「次回チェック」の時刻が表示されます。
- すぐに確認したいときは **今すぐチェック** を押します。
- ウィンドウ右上の **×** を押すと確認が出ます。
  - **はい** … アプリを終了します(監視も止まります)
  - **いいえ** … ウィンドウを最小化して、監視を続けます
- チェック間隔は **その他の設定** タブで変更できます(5〜1440分)。

### 一覧の「状態」の意味

| 状態 | 意味 |
|---|---|
| 監視中 | 現在値が閾値より高い(正常) |
| 閾値以下(通知済み) | 閾値以下になり、今日のメールを送信済み(一覧が赤く表示されます) |
| 閾値以下(未通知) | 閾値以下だがメールを送れなかった。次回チェック時に再送します。メール設定を確認してください |
| 取得失敗 | 株価を取得できなかった(次回チェック時に再取得します) |
| 未チェック | アプリを起動してからまだチェックしていない |

画面下の **ログ** 欄に、チェックの結果やエラーが表示されます。

## 9. 注意事項・既知の制約

- **PC が起動していない・スリープ中・アプリを終了している間は監視しません。** その間に株価が下がっても通知は届きません。
- **株価データについて:** 株価の取得には `yfinance`(Yahoo Finance の **非公式** ライブラリ)を使っています。Yahoo Finance 側の仕様変更により、ある日突然動かなくなる可能性があります。また、データには遅延(日本株で約20分など)があることがあります。投資判断は必ず証券会社などの正式な情報で確認してください。
- **市場が閉まっている時間もチェックします。** 夜間・休日は直近の終値で判定されます(同じ日に何度もメールが届くことはありません)。
  - 東証: 平日 9:00〜15:30(日本時間)
  - 米国市場: 平日 22:30〜翌5:00(日本時間・夏時間)、23:30〜翌6:00(冬時間)
- **日本株の会社名検索** には、日本取引所グループ(JPX)が公開している東証上場銘柄一覧を使っています。一覧は30日ごとに自動で更新されます(**その他の設定** タブの **今すぐ更新** で手動更新も可能)。一覧を取得できない場合でも、証券コード(例: `7203`)や英語の会社名(例: `Toyota`)で検索できます。
- **対象:** 東証上場の日本株と、NYSE / NASDAQ 上場の米国株です。ETF・REIT・投資信託・暗号資産・FX には対応していません。
- **設定やログの保存場所:** アプリのフォルダ内の `data` フォルダに、設定(`settings.json`)、通知済みの記録(`state.json`)、ログ(`app.log`)が保存されます。**アプリのフォルダを移動した場合** は、移動先の `start.bat` から一度起動してください(自動起動の登録が新しい場所に更新されます)。

## 10. 困ったときは

| 症状 | 確認すること |
|---|---|
| `setup.bat` で「Python が見つかりません」と出る | 2 の手順で Python をインストールしたか。インストール時に「Add python.exe to PATH」にチェックを入れたか(入れ忘れた場合は、インストーラーを再実行して **Modify** から設定するか、アンインストールして入れ直してください) |
| `start.bat` を押しても何も起きない | `setup.bat` を先に実行したか。`data\app.log` にエラーが書かれていないか |
| 「すでに起動しています」と出る | アプリは1つしか起動できません。タスクバーの羽根のアイコンをクリックして、起動中の画面を開いてください |
| テストメールが送れない(ログに「ログインに失敗しました」) | 送信元アドレスとアプリパスワードが正しいか。普段の Google パスワードではなく **アプリパスワード** を入れているか。2段階認証が有効か |
| メールが届かない | 迷惑メールフォルダを確認。送信先メールアドレスが正しいか |
| 状態が「取得失敗」になる | インターネットに接続しているか。一時的な障害の可能性もあるので次回のチェックを待つ。続く場合は Yahoo Finance 側の仕様変更の可能性があります |
| 日本株を会社名で検索しても出てこない | **その他の設定** タブで東証の銘柄一覧が「取得日: …」になっているか。「未取得」なら **今すぐ更新** を押す。社名の一部(例: 「三菱UFJ」→「三菱ＵＦＪ」も可)で試す |
| 自動起動しない | **その他の設定** タブのチェックが入っているか。Windows の **設定 → アプリ → スタートアップ** で「pythonw」または「StockAlert」がオフになっていないか |

## 11. アンインストール(削除)の方法

1. アプリの **その他の設定** タブで、自動起動のチェックを外します。
2. アプリを終了します(× → **はい**)。
3. アプリのフォルダごと削除します。
4. (任意)保存したアプリパスワードを削除する場合は、Windows の **コントロールパネル → 資格情報マネージャー → Windows 資格情報** を開き、`StockAlert` を含む項目を削除します。
5. (任意)Google の <https://myaccount.google.com/apppasswords> で、発行したアプリパスワードを削除します。

## 開発者向け

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -t .
```

- ソースコードは `src/stock_alert/` にあります(`core.py`: 判定・状態管理、`prices.py`: 株価取得、`search.py`: 銘柄検索、`mailer.py`: メール送信、`autostart.py`: 自動起動、`gui.py`: 画面)。
- 株価の取得元を変える場合は `prices.py` の `get_current_price()` だけを差し替えてください。
- GUI のテストは、画面のない環境では自動的にスキップされます(Linux では `xvfb-run -a python -m unittest discover -s tests -t .` で実行できます)。
